# Vocal Marketing Site

Marketing site for Vocal - AI agents for home healthcare businesses.

## Development

This is a static site built with HTML, TailwindCSS, and vanilla JavaScript.

To develop locally:
1. Open `index.html` in your browser
2. Make changes to the HTML/CSS/JS
3. Refresh to see changes

## Deployment

The site is deployed on Vercel's edge network for optimal performance.
